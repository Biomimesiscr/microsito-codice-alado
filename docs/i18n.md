# Internationalization (i18n)

The project uses **i18next** + **react-i18next** + **i18next-browser-languagedetector** for multilingual support (Spanish and English).

## Setup

i18n is initialized in `src/i18n.ts` and imported at app startup in `src/main.tsx`:

```ts
// src/main.tsx
import './i18n.ts';
```

### Configuration (`src/i18n.ts`)

```ts
import i18n from 'i18next';
import { initReactI18next } from 'react-i18next';
import LanguageDetector from 'i18next-browser-languagedetector';

import globalEn from './locales/en/global.json';
import globalEs from './locales/es/global.json';

i18n
  .use(LanguageDetector)      // Auto-detect browser language
  .use(initReactI18next)      // Bind to React
  .init({
    resources: {
      en: { global: globalEn },
      es: { global: globalEs },
    },
    fallbackLng: 'en',        // Fallback if key missing or language not found
    defaultNS: 'global',      // Default namespace
    interpolation: {
      escapeValue: false,     // React already escapes
    },
  });

export default i18n;
```

## File Structure

```
src/
├── i18n.ts                   # i18next initialization
└── locales/
    ├── en/
    │   └── global.json       # English translations
    └── es/
        └── global.json       # Spanish translations
```

## Adding Translations

Each locale folder contains JSON files organized by namespace. The default (and currently only) namespace is `global`.

### 1. Define keys in both locale files

**`src/locales/es/global.json`**
```json
{
  "hero": {
    "title": "Códice Alado",
    "subtitle": "Sitio en construcción... pronto estaremos contigo"
  },
  "nav": {
    "menu": "Menú",
    "login": "Iniciar sesión"
  }
}
```

**`src/locales/en/global.json`**
```json
{
  "hero": {
    "title": "Códice Alado",
    "subtitle": "Site under construction... we'll be with you soon"
  },
  "nav": {
    "menu": "Menu",
    "login": "Log in"
  }
}
```

### 2. Use in components

#### `useTranslation` hook (most common)

```tsx
import { useTranslation } from 'react-i18next';

function Hero() {
  const { t } = useTranslation('global');

  return (
    <>
      <h1>{t('hero.title')}</h1>
      <p>{t('hero.subtitle')}</p>
    </>
  );
}
```

#### With interpolation

```json
{ "greeting": "Hello, {{name}}!" }
```

```tsx
<p>{t('greeting', { name: 'Ana' })}</p>
```

#### With plurals

```json
{
  "items": {
    "one": "{{count}} item",
    "other": "{{count}} items"
  }
}
```

```tsx
<p>{t('items', { count: 5 })}</p>
```

## Switching Languages

Use `i18next.changeLanguage()` or the `useTranslation` hook:

```tsx
import { useTranslation } from 'react-i18next';

function LanguagePicker() {
  const { i18n } = useTranslation();

  return (
    <SegmentedToggle
      options={[
        { value: 'es', label: 'Español' },
        { value: 'en', label: 'English' },
      ]}
      value={i18n.language}
      onChange={(lng) => i18n.changeLanguage(lng)}
    />
  );
}
```

The language preference is persisted by `i18next-browser-languagedetector` (localStorage, cookies, etc.) and auto-detected from the browser on first visit.

## Adding a New Language

1. Create a new folder under `src/locales/` (e.g. `src/locales/fr/`).
2. Add `global.json` with all the same keys.
3. Register it in `src/i18n.ts`:

```ts
import globalFr from './locales/fr/global.json';

// inside .init({ resources: { ... } })
fr: { global: globalFr },
```

4. Add the new option to any `SegmentedToggle` used as a language picker.

## Adding a New Namespace

For larger features, you can split translations into separate namespaces:

1. Create a new JSON file in each locale folder (e.g. `settings.json`).
2. Register it in `src/i18n.ts`:

```ts
import settingsEn from './locales/en/settings.json';
import settingsEs from './locales/es/settings.json';

// inside .init({ resources: { ... } })
en: { global: globalEn, settings: settingsEn },
es: { global: globalEs, settings: settingsEs },
```

3. Use it by passing the namespace:

```tsx
const { t } = useTranslation('settings');
<p>{t('someKey')}</p>
```
